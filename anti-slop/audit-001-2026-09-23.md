## Temuan

### 1. (HIGH, R-25) Label kecil putih/transparan di atas hero gradien di bawah ambang AA
Alasan: teks `text-white/70` ukuran 10-12px di atas gradien `#4a4fe9` ke `#7c3aed`
menghasilkan kontras sekitar 4,3:1, di bawah syarat 4,5:1 untuk teks kecil.
Usulan: label kecil menjadi putih solid, subjudul menjadi `text-white/90`.

### 2. (HIGH, R-03) Tombol Hapus dan segmented di bawah target sentuh 44px
Alasan: tombol Hapus (`py-1.5`, sekitar 30px) dan tombol pilih daftar (`py-2.5`,
sekitar 40px) lebih kecil dari minimum 44px.
Usulan: tambah `min-h-[44px]` pada kedua jenis tombol tanpa mengubah tampilan.

### 3. (HIGH, R-27) Tidak ada loading state
Alasan: halaman punya empty state dan error state (toast validasi), tetapi tidak
ada loading state karena data dibaca sinkron dari localStorage tanpa fetch async.
Usulan: nyatakan N/A secara eksplisit, atau tambah gate render sampai hook `ready`.

### 4. (HIGH, R-35) Belum ada click-through tercatat
Alasan: build lolos (`npm run build`), tetapi belum ada verifikasi klik per elemen
(Tambah Monthly, Tambah Free tanpa tanggal, duplikat, cari, hapus, contoh finance,
mode gelap, breakpoint mobile).
Usulan: pemilik klik manual di `/clients`, atau setujui verifikasi inspeksi kode.

### 5. (MEDIUM, R-10) Blur hero di luar daftar izin DESIGN.md
Alasan: 3 chip statistik memakai `backdrop-blur`, sedangkan DESIGN.md hanya
mengizinkan blur di header sticky, backdrop modal, kartu login, dan panel sync.
(DashboardPage memakai pola yang sama, jadi ini preseden repo, bukan kasus unik.)
Usulan: hapus `backdrop-blur` pada chip hero (transparansi `bg-white/15` tetap terbaca).

### 6. (LOW, R-32) Tombol tanpa focus ring eksplisit
Alasan: input punya `focus:ring-2`, tetapi tombol hanya mengandalkan outline
bawaan browser sehingga indikator fokus keyboard kurang tegas.
Usulan: tambah `focus-visible:ring-2 focus-visible:ring-brand-500/50` pada tombol.
